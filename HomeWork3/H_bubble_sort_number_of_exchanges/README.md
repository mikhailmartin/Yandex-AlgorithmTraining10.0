# H. Сортировка пузырьком: количество обменов

|                     |                                  |
|---------------------|----------------------------------|
| Ограничение времени | 1 секунда                        |
| Ограничение памяти  | 64Mb                             |
| Ввод                | стандартный ввод или input.txt   |
| Вывод               | стандартный вывод или output.txt |

Определите, сколько обменов сделает алгоритм пузырьковой сортировки по
возрастанию для данного массива.


## Формат ввода:
На первой строке дано число $N$ ($1 \le N \le 100\ 000$) – количество элементов
в массиве. На второй строке – сам массив. Гарантируется, что все элементы
массива различны и не превышают по модулю $10^9$.


## Формат вывода:
Выведите одно число – количество обменов пузырьковой сортировки.


### Пример 1:
#### Ввод:
```
5
1 2 3 4 5
```
#### Вывод:
```
0
```

---

### Пример 2:
#### Ввод:
```
5
5 4 3 2 1
```
#### Вывод:
```
10
```
